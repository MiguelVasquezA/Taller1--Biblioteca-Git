# Sistema de Gestión de Biblioteca

Taller 1 - Programación III - UPC

## Autor

Miguel Vásquez Aguirre

Abraham Medina Rodrigues

## Descripción

Aplicación de consola desarrollada en Java para gestionar clientes, libros y préstamos de una biblioteca.

La información se almacena en memoria utilizando ArrayList y se implementan operaciones CRUD para clientes y libros, además del registro y devolución de préstamos.

## Cómo ejecutar

1. Abrir el proyecto en NetBeans.
2. Compilar el proyecto Maven.
3. Ejecutar la clase Main.java.

## Funcionalidades

- CRUD de Clientes
- CRUD de Libros
- Registro de Préstamos
- Devolución de Préstamos
- Listado de Préstamos
- Menú principal por consola
